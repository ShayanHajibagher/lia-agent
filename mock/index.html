محیط تست لیا

آینهٔ سایت لیارا + پنل جعلی، برای تست ویجت و جریان دیپلوی بدون تماس با سرویس واقعی.

فقط محلی — 127.0.0.1

این محیط چه چیزهایی دارد؟

صفحه‌های عمومی سایت لیارا عیناً دانلود شده‌اند (HTML/CSS/فونت/تصویر) و مسیر دارایی‌ها حفظ شده است. پنل (console.liara.ir) پشت لاگین است و قابل آینه‌کردن نبود؛ صفحه‌های آن بازسازی شده‌اند تا مسیر «ساخت برنامه → انتخاب پلتفرم → انتخاب پلن → تنظیمات → استقرار» قابل کلیک و تست باشد.

لینک‌های پنل داخل صفحه‌های آینه‌شده به همین پنل جعلی اشاره می‌کنند. اجرا: node tools/serve.mjs

۱) صفحه‌های آینه‌شدهٔ liara.ir

محتوای واقعی سایت؛ ویجت لیا بعداً روی همین‌ها سوار می‌شود.

صفحهٔ اصلیمعرفی محصول، ناوبری، CTA/ قیمت‌هاپلن‌های PaaS/DBaaS/IaaS و تعرفهٔ ترافیک/pricing/ هاست ابری ساعتیپلن‌ها و منابع سخت‌افزاری/products/cloud-host/ دیتابیس ابریDBaaS و پلن‌ها/products/cloud-database/ هاست رایگانشروع رایگان و محدودیت‌ها/products/free-cloud-host/

۲) پنل جعلی (بازسازی‌شدهٔ console.liara.ir)

هر مرحله یک صفحهٔ مستقل است تا «آگاهی از صفحه» و هایلایت کردن هدف تست شود.

۳) پروژه‌های نمونهٔ تست

برای آپلود در چت لیا. هر کدام یک حالت را پوشش می‌دهد (سالم، باگ‌دار، نامناسب، …).

فروشگاه Next.jsوب مناسب، با چند باگ رایجnextjs-shop.zip سایت استاتیکمناسب، پیشنهاد سرو استاتیکstatic-portfolio.zip ربات تلگرامنامناسب برای هاست وب → مناسب‌سازیtelegram-bot.zip ابزار CLIنامناسب → لایهٔ وبcli-json-tool.zip اسکریپت پایتوننامناسب → سرور HTTPpython-scraper.zip API لاراولوب با دیتابیسlaravel-api.zip zip بی‌ربطسورس برنامه نیست → سؤال می‌پرسدnot-an-app.zip

۴) ایجنت لیا

ویجت روی همهٔ صفحه‌ها سوار شده است؛ دکمهٔ دایره‌ای گوشهٔ راست پایین صفحه.

سلامت ایجنتوضعیت API و حالت مدل زبانی/api/health تست روی صفحهٔ قیمت‌هاباز شدن خودکار سایدبار/pricing/?lia=open تست راهنما در پنلهایلایت مرحلهٔ انتخاب پلن/panel/apps/new/plan/

۵) فهرست ماشین‌خوان

برای اسکریپت‌های ایجنت و تست خودکار.

قدم بعدی

ویجت لیا (دکمهٔ شناور + سایدبار چت) روی همین صفحه‌ها سوار می‌شود. میزبان تست مسیر صفحه را در window.__LIA_HOST__ و پنل جعلی وضعیت انتخاب‌ها را در window.__LIA_PANEL__ اعلام می‌کند؛ همان چیزی که «آگاهی از صفحه» به آن تکیه می‌کند.
